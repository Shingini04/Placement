## Right / Left View of Binary Tree

* **Goal:** Return the visible node at each depth level when viewing the tree from the right (last node per level) or left (first node per level).

### 1. Recursive DFS (Reverse Preorder — Optimal Space)
* **Time:** $O(N)$ | **Space:** $O(H)$ recursion stack ($O(N)$ skewed, $O(\log N)$ balanced)
* **Key Idea:** Visit `Root -> Right -> Left` for **Right View** (or `Root -> Left -> Right` for **Left View**). The first time a `level` is reached (`level == ans.size()`), that node is the outermost visible node at that depth.

```text
// Right View: Root -> Right -> Left
rightDFS(node, level, ans):
    if node == NULL: return
    if level == ans.size():
        ans.push(node->val)
    rightDFS(node->right, level + 1, ans)
    rightDFS(node->left,  level + 1, ans)

// Left View: swap traversal order to Root -> Left -> Right
```

---

### 2. Iterative BFS (Level-Order Without 2D Matrix)
* **Time:** $O(N)$ | **Space:** $O(W)$ queue ($W \le N/2$ max tree width)
* **Key Idea:** Snapshot `sz = q.size()` per level; record `node->val` when `i == sz - 1` (**Right View**) or `i == 0` (**Left View**).

```text
rightViewBFS(root):
    ans = []
    if root == NULL: return ans
    q = queue([root])

    while !q.empty():
        sz = q.size()
        for i = 0 to sz - 1:
            node = q.pop()
            if i == sz - 1: ans.push(node->val)   // use i == 0 for Left View
            if node->left:  q.push(node->left)
            if node->right: q.push(node->right)

    return ans
```

---

### Edge Cases & Gotchas
* **Empty tree (`root == NULL`):** Returns `[]`.
* **Hidden deep left branch trap:** Even if the right subtree ends early, deeper nodes in the left subtree remain visible from the right (e.g., `[1, 2, 3, 4]` $\rightarrow$ Right View is `[1, 3, 4]`). Both DFS (`level == ans.size()`) and BFS handle this automatically; never just follow `root = root->right`.
* **Follow-ups:** Top View of BT (BFS + horizontal distance `hd` map, first seen per `hd`), Bottom View of BT (BFS + `hd` map, overwrite with last seen per `hd`), Boundary Traversal of BT.
