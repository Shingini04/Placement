## Serialize and Deserialize Binary Tree

* **Key Requirement:** Single traversal (Preorder or Level-Order) is sufficient to uniquely reconstruct a binary tree **iff** null child pointers are explicitly encoded with a sentinel (e.g., `#`).

### 1. Level-Order BFS (Queue-Based)
* **Time:** $O(N)$ | **Space:** $O(N)$ (queue + string buffer)
* **Key Idea:** Push `NULL` children into the queue as well; emit `#` on dequeue so every non-null node pairs cleanly with the next two tokens in `deserialize`.

```text
serialize(root):
    if root == NULL: return ""
    q = queue([root]), out = ""
    while !q.empty():
        node = q.pop()
        if node == NULL:
            out += "#,"
        else:
            out += to_string(node->val) + ","
            q.push(node->left)
            q.push(node->right)
    return out

deserialize(data):
    if data.empty(): return NULL
    tokens = split(data, ',')
    root = new TreeNode(stoi(tokens[0]))
    q = queue([root]), idx = 1

    while !q.empty():
        node = q.pop()
        if tokens[idx] != "#":
            node->left = new TreeNode(stoi(tokens[idx]))
            q.push(node->left)
        idx++
        if tokens[idx] != "#":
            node->right = new TreeNode(stoi(tokens[idx]))
            q.push(node->right)
        idx++

    return root
```

### 2. Preorder DFS (Cleaner / No Queue)
* **Time:** $O(N)$ | **Space:** $O(N)$ ($O(H)$ recursion stack + string)
* **Key Idea:** Emit `Root,Left,Right` with `#` for nulls; consume tokens sequentially with a shared index pointer.

```text
serializeDFS(node, out):
    if node == NULL:
        out += "#,"
        return
    out += to_string(node->val) + ","
    serializeDFS(node->left, out)
    serializeDFS(node->right, out)

deserializeDFS(tokens, idx):
    val = tokens[idx++]
    if val == "#": return NULL
    node = new TreeNode(stoi(val))
    node->left  = deserializeDFS(tokens, idx)
    node->right = deserializeDFS(tokens, idx)
    return node
```

---

### Edge Cases & Gotchas
* **Empty tree (`root == NULL`):** `serialize` returns `""`, `deserialize("")` returns `NULL`.
* **Delimiters & multi-digit / negative values:** Always delimit tokens (e.g., `,`) so `-12` or `1,2` doesn't merge into `12`.
* **BST optimization:** For a Binary Search Tree, `#` sentinels aren't needed—Preorder alone + `(minBound, maxBound)` range checks reconstructs it in $O(N)$ with minimal string size.
* **Follow-ups:** Serialize/Deserialize BST (no `#`), Serialize/Deserialize N-ary Tree (store child count or closing sentinel `)` after children).
