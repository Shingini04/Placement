## Longest Common Prefix

* **Goal:** Find the longest shared prefix across all $N$ strings ($M = \max \text{string length}$), or `""` if none exists.

### 1. Vertical Scan (Optimal)
* **Time:** $O(N \cdot M)$ (stops early on first mismatch) | **Space:** $O(1)$ auxiliary
* **Key Idea:** Use `strs[0]` as reference; check column `i` across every string `j = 1..N-1` until a string ends or differs.

```text
longestCommonPrefix(strs):
    if strs.empty(): return ""

    for i = 0 to strs[0].size() - 1:
        ch = strs[0][i]
        for j = 1 to strs.size() - 1:
            if i == strs[j].size() or strs[j][i] != ch:
                return strs[0].substr(0, i)

    return strs[0]
```

---

### 2. Lexicographical Sorting
* **Time:** $O(N \cdot M \log N)$ ($O(M)$ per string comparison during sort) | **Space:** $O(1)$ auxiliary (in-place sort)
* **Key Idea:** After sorting, `strs[0]` and `strs[N - 1]` differ the most—their common prefix is guaranteed to be shared by all intermediate strings.

```text
longestCommonPrefix(strs):
    if strs.empty(): return ""
    sort(strs)

    first = strs[0], last = strs[N - 1]
    i = 0
    while i < min(first.size(), last.size()) and first[i] == last[i]:
        i++

    return first.substr(0, i)
```

---

### Edge Cases & Gotchas
* **Empty array or empty string element (`[""]` / `["", "ab"]`):** Both return `""` safely.
* **Single string (`["abc"]`):** Returns `"abc"`.
* **Bounds check order:** Always check `i == strs[j].size()` **before** `strs[j][i] != ch` to avoid out-of-bounds reads when a later string is shorter than `strs[0]`.
* **Follow-ups:** Longest Common Prefix with Trie (when strings are inserted/queried dynamically), Longest Common Prefix of Two Arrays (LeetCode 3043 — hash all prefixes or Trie).
