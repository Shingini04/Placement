## Minimum Number of Bracket Reversals

* **Goal:** Find the minimum flips (`'('` $\leftrightarrow$ `')'`) needed to balance a parentheses string `s`, or return `-1` if impossible (`s.size()` is odd).

### 1. Greedy Balance Counter (Optimal Space)

* **Time:** $O(N)$ | **Space:** $O(1)$
* **Key Idea:** Cancel out all already-balanced `()` pairs. The remaining unmatched brackets always collapse into the form `)))...(((` (`close` unmatched `')'` followed by `open` unmatched `'('`). Fixing two identical adjacent brackets (`))` or `((`) takes **1** flip, while fixing the boundary pair `)(` takes **2** flips—giving $\lceil \text{open}/2 \rceil + \lceil \text{close}/2 \rceil$.

```cpp
class Solution {
public:
    int countRev(string s) {
        if (s.size() % 2 != 0) return -1;

        int open = 0, close = 0;
        for (char c : s) {
            if (c == '(') {
                open++;
            } else {
                if (open > 0) open--;   // cancels a valid "()" pair
                else close++;           // unmatched ')'
            }
        }

        return (open + 1) / 2 + (close + 1) / 2;
    }
};

```

---

### 2. Stack Cancellation Alternative

* **Time:** $O(N)$ | **Space:** $O(N)$
* **Key Idea:** Push `'('` onto a stack; pop when `')'` sees `'('` on top, otherwise push `')'`. Count remaining `open` and `close` in the stack and apply `(open + 1) / 2 + (close + 1) / 2`.

---

### Where to Use This Technique

1. **Valid-Pair Cancellation + Residual Counting:** Whenever valid local pairs (`()`, `ab`, adjacent duplicates) can be greedily eliminated in one pass, reducing the entire problem to counting the leftover irreducible prefix/suffix.
2. **Ceiling Division Parity Formula (`(a + 1) / 2 + (b + 1) / 2`):** Whenever items are fixed in pairs of cost 1, except a single cross-boundary pair of cost 2 when both counts are odd.

### Follow-Up & Similar Problems

* **Minimum Add to Make Parentheses Valid (LeetCode 921):** Same `open` / `close` cancellation, but insertions instead of flips are allowed—answer is simply `open + close`.
* **Minimum Number of Swaps to Make the String Balanced (LeetCode 1963):** Swap two brackets instead of flipping; each swap fixes up to two unmatched pairs, giving `(close + 1) / 2`.
* **Minimum Remove to Make Valid Parentheses (LeetCode 1249):** Track unmatched indices via stack/counters and delete them in $O(N)$.
* **Valid Parentheses (LeetCode 20):** Multi-bracket (`()`, `{}`, `[]`) stack matching baseline.
