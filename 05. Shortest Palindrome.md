## Shortest Palindrome

* **Goal:** Prepend the fewest characters to the start of `s` to make the entire string a palindrome.

### 1. KMP LPS Array on `s + '$' + reverse(s)` (Optimal)

* **Time:** $O(N)$ | **Space:** $O(N)$
* **Key Idea:** Adding characters to the front only wraps around the non-palindromic suffix of `s`. Therefore, finding the **longest palindromic prefix** of `s` (length $L$) tells us we only need to prepend the reverse of the remaining $N - L$ suffix characters. Building the KMP `lps` array on `s + '$' + rev` makes `lps.back()` equal the longest prefix of `s` matching a suffix of `rev`—which is the exact longest palindromic prefix of `s` (the `'$'` separator prevents overlap across the boundary).

```cpp
class Solution {
private:
    vector<int> computeLPS(const string& str) {
        int n = str.size();
        vector<int> lps(n, 0);
        int i = 1, j = 0;

        while (i < n) {
            if (str[i] == str[j]) {
                lps[i] = j + 1;
                i++;
                j++;
            } else {
                if (j > 0) j = lps[j - 1];
                else i++;
            }
        }
        return lps;
    }

public:
    string shortestPalindrome(string s) {
        string rev = s;
        reverse(rev.begin(), rev.end());

        string combined = s + '$' + rev;
        vector<int> lps = computeLPS(combined);

        int toAddLen = s.size() - lps.back();
        return rev.substr(0, toAddLen) + s;
    }
};

```

---

### Where to Use This Technique

1. **Longest Palindromic Prefix / Suffix in $O(N)$:** Concatenating `s + '#' + reverse(s)` (or `reverse(s) + '#' + s` for palindromic suffix) and reading `lps.back()` finds boundary palindromes in linear time without Manacher's algorithm.
2. **String Border / Overlap Matching (`pattern + '#' + text`):** Whenever a problem asks for the longest prefix of string $A$ that matches a suffix of string $B$, build KMP `lps` on `A + '#' + B` and inspect `lps.back()`.

### Follow-Up Problems

* **Longest Happy Prefix (LeetCode 1392):** Directly compute `lps.back()` on `s` itself to find the longest proper prefix that is also a suffix.
* **Minimum Insertion Steps to Make a String Palindrome (LeetCode 1312):** Follow-up where insertions are allowed **anywhere** (not just at the beginning)—solved via DP: `n - LCS(s, reverse(s))` in $O(N^2)$ time.
