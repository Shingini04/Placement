## Lowest Common Ancestor (LCA) in Binary Tree

* **Definition:** Deepest node $T$ having both $p$ and $q$ as descendants (a node is a descendant of itself).

### Optimal (Single-Pass Postorder DFS)
* **Time:** $O(N)$ | **Space:** $O(H)$ recursion stack ($O(N)$ skewed, $O(\log N)$ balanced)
* **Key Idea:** Propagate matched targets (`p` or `q`) upward. The first node receiving non-null returns from **both** `left` and `right` subtrees is the split point (LCA).

```text
LCA(root, p, q):
    if root == NULL or root == p or root == q:
        return root

    left = LCA(root->left, p, q)
    right = LCA(root->right, p, q)

    if left != NULL and right != NULL:
        return root                     // p and q split across subtrees
    return (left != NULL) ? left : right
```

---

### Edge Cases & Gotchas
* **One node is an ancestor of the other (e.g., `p = 5, q = 4` where `4` is under `5`):** Hits `root == p` early and returns `5` without needing to search below `5`; the other branch returns `NULL`, so `5` bubbles all the way up.
* **Caveat (Existence guarantee):** Assumes **both** `p` and `q` exist in the tree. If one might be missing (LCA II), you must track `foundP` and `foundQ` booleans rather than returning early on the first match.
* **Pointer vs. Value:** Compare node pointers (`root == p`), not `root->val == p->val` (though values are unique here).
