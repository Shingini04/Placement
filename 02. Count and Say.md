# Count and Say & Run-Length Encoding (RLE) Pattern

## 1. Problem Overview
* **Base Case:** `countAndSay(1) = "1"`
* **Recurrence:** For $n > 1$, generate `countAndSay(n)` by reading `countAndSay(n - 1)` from left to right and replacing every maximal contiguous group of identical digits with `<count><digit>`.
* **Sequence Progression:**
  * $n = 1 \rightarrow \text{"1"}$
  * $n = 2 \rightarrow \text{"11"}$ *(one 1)*
  * $n = 3 \rightarrow \text{"21"}$ *(two 1s)*
  * $n = 4 \rightarrow \text{"1211"}$ *(one 2, one 1)*
  * $n = 5 \rightarrow \text{"111221"}$ *(one 1, one 2, two 1s)*
  * $n = 6 \rightarrow \text{"312211"}$ *(three 1s, two 2s, one 1)*

---

## 2. Core Logic (Consecutive Run Tracking)
1. Start at index `i = 1` with `cn = 1` (representing `s[0]`).
2. Compare `s[i]` with `s[i - 1]`:
   * **Same character:** Increment `cn++`.
   * **Different character:** Emit `cn` and `s[i - 1]` to `res`, then reset `cn = 1`.
3. **Post-loop flush:** After the loop finishes, emit the final `cn` and `s.back()` because no mismatch occurs after the last character.

---

## 3. C++ Implementations

### Approach A: Recursive
```cpp
class Solution {
public:
    string countAndSay(int n) {
        if (n == 1) return "1";

        string s = countAndSay(n - 1);
        string res = "";
        int cn = 1;

        for (int i = 1; i < s.size(); i++) {
            if (s[i] == s[i - 1]) {
                cn++;
            } else {
                res += ('0' + cn);
                res += s[i - 1];
                cn = 1;
            }
        }

        // Flush the final consecutive group
        res += ('0' + cn);
        res += s.back();
        return res;
    }
};
```

### Approach B: Iterative (Saves Recursion Stack)
```cpp
class Solution {
public:
    string countAndSay(int n) {
        string s = "1";

        for (int step = 2; step <= n; step++) {
            string res = "";
            int cn = 1;

            for (int i = 1; i < s.size(); i++) {
                if (s[i] == s[i - 1]) {
                    cn++;
                } else {
                    res += ('0' + cn);
                    res += s[i - 1];
                    cn = 1;
                }
            }

            res += ('0' + cn);
            res += s.back();
            s = res;
        }

        return s;
    }
};
```

---

## 4. Complexity Analysis
* **Time Complexity:** $O(N \cdot L)$, where $L$ is the string length at step $n$ (grows by Conway's constant $\lambda \approx 1.3036$ per step, bounded for $n \le 30$).
* **Space Complexity:**
  * **Iterative:** $O(L)$ auxiliary space to build the next string.
  * **Recursive:** $O(N + L)$ including the $O(N)$ call stack.

---

## 5. Where to Use This Logic (Pattern Recognition)

This exact **`cn = 1` + adjacent comparison (`arr[i] == arr[i - 1]`) + post-loop flush** template applies whenever a problem involves **contiguous runs/streaks** in an array or string.

### When to Recognize the Pattern
* **Lossless Compression / Encoding:** Compressing repeated characters or numbers into `(value, frequency)` pairs.
* **Streak & Block Counting:** Finding longest consecutive identical elements, counting valid subarrays of identical items, or enforcing maximum consecutive duplicates.
* **Block Partitioning / Validation:** Checking if every contiguous block of identical characters satisfies a size rule (e.g., divisible by 2 or 3).
* **Two-Pointer In-Place Grouping:** Rewriting an array in-place by collapsing consecutive duplicates (`read` pointer scans runs, `write` pointer outputs compressed form).

### Reusable General Template
```cpp
int cn = 1;
for (int i = 1; i < n; i++) {
    if (arr[i] == arr[i - 1]) {
        cn++;
    } else {
        // Process completed run of (arr[i - 1], cn)
        cn = 1;
    }
}
// Process final run of (arr[n - 1], cn)
```
