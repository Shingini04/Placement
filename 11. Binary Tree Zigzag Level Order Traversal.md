## Binary Tree Zigzag Level Order Traversal

* **Traversal Order:** Level 0 left-to-right, Level 1 right-to-left, alternating at each depth.

### 1. BFS + Index Placement (Optimal — No Extra Reverse Pass)
* **Time:** $O(N)$ | **Space:** $O(W)$ auxiliary queue ($W \le N/2$ max tree width) + $O(N)$ output
* **Key Idea:** Keep standard left-to-right BFS queue order (`push(left)` then `push(right)`), pre-allocate `row(sz)`, and write directly to `idx = leftToRight ? i : (sz - 1 - i)`.

```text
zigzagLevelOrder(root):
    ans = []
    if root == NULL: return ans

    q = queue([root])
    leftToRight = true

    while !q.empty():
        sz = q.size()
        row = array of size sz

        for i = 0 to sz - 1:
            node = q.pop()
            idx = leftToRight ? i : (sz - 1 - i)
            row[idx] = node->val

            if node->left:  q.push(node->left)
            if node->right: q.push(node->right)

        leftToRight = !leftToRight
        ans.push(row)

    return ans
```

---

### 2. Two-Stack / Deque Alternative
* **Time:** $O(N)$ | **Space:** $O(W)$
* **Key Idea:** Maintain two stacks (`currLevel`, `nextLevel`); push children `left` then `right` on L$\rightarrow$R levels, and `right` then `left` on R$\rightarrow$L levels, swapping stacks at the end of each level.

---

### Edge Cases & Gotchas
* **Empty tree (`root == NULL`):** Return `[]` immediately before pushing `root`.
* **Child enqueue order trap:** Always enqueue `node->left` then `node->right` into the BFS queue—only change the **output index** (`sz - 1 - i`), not the queue insertion order.
* **Follow-ups:** Boundary Traversal of BT, Vertical Order Traversal, Binary Tree Right Side View.
