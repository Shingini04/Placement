## Check for Balanced Binary Tree

* **Definition:** A binary tree is height-balanced iff for **every** node, $\vert{}height(left) - height(right)\vert{} \le 1$.

### 1. Brute Force (Top-Down)
* **Time:** $O(N^2)$ (recomputes subtree height at every node) | **Space:** $O(H)$
* **Key Idea:** At each node, compute `height(left)` and `height(right)`, check $\vert{}lh - rh\vert{} \le 1$, and recurse on both children.

---

### 2. Optimal (Bottom-Up Postorder DFS with Sentinel `-1`)
* **Time:** $O(N)$ (single postorder pass) | **Space:** $O(H)$ recursion stack ($O(N)$ skewed, $O(\log N)$ balanced)
* **Key Idea:** Return the actual subtree height if balanced, or `-1` immediately as a failure signal to short-circuit upward.

```text
dfsHeight(node):
    if node == NULL:
        return 0

    lh = dfsHeight(node->left)
    if lh == -1: return -1

    rh = dfsHeight(node->right)
    if rh == -1: return -1

    if abs(lh - rh) > 1:
        return -1

    return 1 + max(lh, rh)

isBalanced(root):
    return dfsHeight(root) != -1
```

---

### Edge Cases & Gotchas
* **Empty tree (`root == NULL`):** Returns `0` from `dfsHeight` $\rightarrow$ `true` (balanced).
* **Global vs. root-only trap:** Checking $|height(root->left) - height(root->right)| \le 1$ only at the root fails when subtrees are internally skewed (e.g., `[1, 2, 2, 3, null, null, 3, 4, null, null, 4]`). Every node must satisfy the invariant.
