## Construct Binary Tree from Preorder and Inorder

* **Key Properties:**
  * **Preorder** (`Root -> Left -> Right`): First element is always the subtree root.
  * **Inorder** (`Left -> Root -> Right`): Locating the root splits elements into `[inStart .. inRoot - 1]` (left subtree) and `[inRoot + 1 .. inEnd]` (right subtree).

### 1. Subarray Boundary Index Approach (Optimal)
* **Time:** $O(N)$ ($O(1)$ hashmap lookup per node) | **Space:** $O(N)$ (`inMap` + $O(H)$ recursion stack)
* **Key Idea:** Count `numsLeft = inRoot - inStart` to slice `preorder` cleanly without copying arrays.

```text
buildTree(preorder, inorder):
    inMap = { inorder[i] -> i for i in 0..N-1 }
    return helper(preorder, 0, N - 1, inorder, 0, N - 1, inMap)

helper(pre, preStart, preEnd, in, inStart, inEnd, inMap):
    if preStart > preEnd or inStart > inEnd:
        return NULL

    root = new TreeNode(pre[preStart])
    inRoot = inMap[root->val]
    numsLeft = inRoot - inStart

    root->left  = helper(pre, preStart + 1, preStart + numsLeft, in, inStart, inRoot - 1, inMap)
    root->right = helper(pre, preStart + numsLeft + 1, preEnd,   in, inRoot + 1, inEnd,   inMap)
    return root
```

---

### 2. Clean Alternative: Global/Reference `preIdx` Pointer
* **Time:** $O(N)$ | **Space:** $O(N)$
* **Key Idea:** Because preorder visits `Root`, then the entire `Left` subtree, then `Right`, advancing a single `preIdx++` sequentially matches the exact DFS build order.

```text
helper(pre, preIdx, inStart, inEnd, inMap):
    if inStart > inEnd:
        return NULL

    root = new TreeNode(pre[preIdx++])
    inRoot = inMap[root->val]

    root->left  = helper(pre, preIdx, inStart, inRoot - 1, inMap)
    root->right = helper(pre, preIdx, inRoot + 1, inEnd,   inMap)
    return root
```

---

### Edge Cases & Gotchas
* **Unique values requirement:** Hashmap lookup (`inMap[val]`) works **only** because all node values are guaranteed unique; duplicate values make tree reconstruction ambiguous.
* **Postorder + Inorder variant:** Read `postorder` from the **back** (`postEnd` or `postIdx--`), and build **`root->right` BEFORE `root->left`** (since `Postorder` reversed is `Root -> Right -> Left`).
* **Preorder + Postorder:** Does **not** uniquely determine a binary tree unless every internal node has 2 children (Full Binary Tree).
