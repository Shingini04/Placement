## Binary Tree Inorder Traversal

* **Traversal Order:** `Left -> Root -> Right`

### 1. Recursive
* **Time:** $O(N)$ | **Space:** $O(H)$ auxiliary recursion stack ($O(N)$ worst-case skewed tree, $O(\log N)$ balanced)

```text
inorder(node, ans):
    if node == NULL:
        return
    inorder(node->left, ans)
    ans.push(node->val)
    inorder(node->right, ans)
```

---

### 2. Iterative (Explicit Stack)
* **Time:** $O(N)$ | **Space:** $O(H)$ auxiliary stack
* **Key Idea:** Push all left-spine nodes onto the stack until hitting `NULL`, then pop, record value, and shift to `node->right`.

```text
st = empty stack, curr = root, ans = []

while curr != NULL or !st.empty():
    while curr != NULL:
        st.push(curr)
        curr = curr->left
    curr = st.pop()
    ans.push(curr->val)
    curr = curr->right

return ans
```

---

### Key Properties & Gotchas
* **BST Property:** Inorder traversal of a Binary Search Tree always yields elements in **strictly non-decreasing (sorted) order**.
* **Space Optimization:** **Morris Inorder Traversal** achieves $O(1)$ auxiliary space via temporary threaded links from the inorder predecessor's right pointer back to `curr`.
* **Follow-ups:** Validate BST, $K$-th Smallest Element in BST, Recover BST (two swapped nodes), Construct Tree from Preorder + Inorder.
