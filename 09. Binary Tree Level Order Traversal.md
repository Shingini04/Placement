## Binary Tree Level Order Traversal

* **Traversal Order:** Top-to-bottom, left-to-right, grouped by depth level (`vector<vector<int>>`).

### 1. Iterative BFS (Queue + Level Size Snapshot — Optimal)
* **Time:** $O(N)$ (each node enqueued/dequeued once) | **Space:** $O(W)$ auxiliary queue ($W \le N/2$ max tree width) + $O(N)$ output
* **Key Idea:** Snapshot `sz = q.size()` at the start of each `while` iteration—that exact count is the number of nodes belonging to the current level.

```text
levelOrder(root):
    ans = []
    if root == NULL: return ans

    q = queue([root])
    while !q.empty():
        sz = q.size()
        level = []
        for i = 0 to sz - 1:
            node = q.pop()
            level.push(node->val)
            if node->left:  q.push(node->left)
            if node->right: q.push(node->right)
        ans.push(level)

    return ans
```

---

### 2. Recursive DFS (Depth-Indexed Buckets)
* **Time:** $O(N)$ | **Space:** $O(H)$ recursion stack + $O(N)$ output
* **Key Idea:** Pass `depth` down; whenever `depth == ans.size()`, append a new level bucket, then push `node->val` into `ans[depth]`.

```text
dfs(node, depth, ans):
    if node == NULL: return
    if depth == ans.size():
        ans.push([])
    ans[depth].push(node->val)
    dfs(node->left, depth + 1, ans)
    dfs(node->right, depth + 1, ans)
```

---

### Edge Cases & Gotchas
* **Empty tree (`root == NULL`):** Must return `{}` immediately before pushing `root` onto `q` (never push `NULL` into the queue).
* **Dynamic `q.size()` trap:** Always cache `int sz = q.size()` **before** the inner `for` loop—evaluating `i < q.size()` dynamically mixes next-level children into the current level.
* **Follow-ups:** Zigzag Level Order (flip `level` or index `sz - 1 - i` on odd levels), Bottom-Up Level Order (`reverse(ans)` at the end), Right Side View (take `level.back()` at each level).
