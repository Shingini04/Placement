## Reverse Words in a String — In-Place Cheatsheet

### 3-Step Mental Model

1. **Flip the whole string:** Puts words in the right sentence order, with individual letters backwards (`"  the   sky  "` $\rightarrow$ `"  yks   eht  "`).
2. **Compact & un-flip each word:** Slide non-space characters to the front (`i`), flip each copied word (`start..end`) right-side up, and append a single `' '`.
3. **Cut the leftover tail:** Step back `i` if a trailing space was added (when original input had leading spaces), then return `s.substr(0, i)`.

---

### Pointer Roles

| Variable | Role |
| --- | --- |
| `j` | **Reader:** Scans raw string, skips `' '`, reads word characters |
| `i` | **Writer:** Builds clean compacted string from index `0` |
| `start` | First index of the newly copied word (`i` before copying) |
| `end` | Last index of the newly copied word (`i - 1` after copying) |

---

### Reference Implementation ($O(N)$ Time, $O(1)$ Space)

```cpp
class Solution {
private:
    void reverseString(string &s, int start, int end) {
        while (start < end) {
            swap(s[start++], s[end--]);
        }
    }

public:
    string reverseWords(string s) {
        int n = s.length();
        reverseString(s, 0, n - 1);

        int i = 0, j = 0, start = 0, end = 0;

        while (j < n) {
            while (j < n && s[j] == ' ') j++;
            if (j == n) break;

            start = i;
            while (j < n && s[j] != ' ') {
                s[i++] = s[j++];
            }
            end = i - 1;

            reverseString(s, start, end);

            if (j < n) s[i++] = ' ';
        }

        if (i > 0 && s[i - 1] == ' ') i--;
        return s.substr(0, i);
    }
};

```

---

### Where to Use This Pattern

* **Whole-then-Block Reversal:** Reordering variable-length segments or shifting elements in-place without extra memory.
* **Read/Write Two-Pointer Compaction (`j` reader, `i` writer):** Filtering or collapsing redundant spaces/duplicates in-place in one linear pass.
