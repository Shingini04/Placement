## Maximum Depth in Binary Tree

### 1. Recursive (DFS Postorder — Optimal for Balanced Trees)
* **Time:** $O(N)$ | **Space:** $O(H)$ recursion stack ($O(N)$ skewed, $O(\log N)$ balanced)
* **Key Idea:** Depth of any node is `1 + max(depth(left), depth(right))`.

```text
maxDepth(root):
    if root == NULL:
        return 0
    left = maxDepth(root->left)
    right = maxDepth(root->right)
    return 1 + max(left, right)
```

---

### 2. Iterative (Level-Order BFS)
* **Time:** $O(N)$ | **Space:** $O(W)$ queue size ($W$ = max width, up to $N/2$ in a full tree)
* **Key Idea:** Process the tree level-by-level using `q.size()` to snapshot each level and increment `depth` after draining it.

```text
maxDepth(root):
    if root == NULL:
        return 0
    q = queue([root]), depth = 0

    while !q.empty():
        sz = q.size()
        for i = 0 to sz - 1:
            node = q.pop()
            if node->left:  q.push(node->left)
            if node->right: q.push(node->right)
        depth++

    return depth
```

---

### Edge Cases & Gotchas
* **Empty tree (`root == NULL`):** Returns `0`; single root node returns `1` (counts nodes along longest root-to-leaf path, not edges).
* **Space trade-off:** DFS uses $O(N)$ space on a skewed tree ($O(\log N)$ on balanced); BFS uses $O(N)$ space on a complete/full tree ($O(1)$ on skewed).
* **Follow-ups:** Minimum Depth of BT (careful with single-child nodes), Diameter of BT (`left + right` at each node), Check Balanced BT (return `-1` early if `|left - right| > 1`).
